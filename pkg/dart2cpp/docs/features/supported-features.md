## ❌ 不支持的特性

### 🚫 反射和元编程

| 不支持特性 | 原因 | 替代方案 |
|-----------|------|---------|
| `dart:mirrors` | C++ 无原生反射支持 | 代码生成或手动实现 |
| 运行时类型检查 | 性能和复杂性考虑 | 编译时类型检查 |
| 动态方法调用 | 类型安全要求 | 静态方法调用 |
| 注解处理 | 编译器限制 | 预处理器宏 |

### 🚫 平台特定特性

| 不支持特性 | 原因 | 替代方案 |
|-----------|------|---------|
| `dart:io` | 平台依赖 | 使用 C++ 标准库 |
| `dart:html` | Web 特定 | 不适用于 C++ |
| `dart:ui` | Flutter 特定 | 不适用于 C++ |
| Isolates | 并发模型差异 | 使用 C++ 线程 |

### 🚫 高级语言特性

| 不支持特性 | 原因 | 替代方案 |
|-----------|------|---------|
| 动态类型 | 类型安全要求 | 静态类型声明 |
| `noSuchMethod` | 动态分发 | 编译时检查 |
| 符号 (Symbols) | 反射依赖 | 字符串常量 |
| 类型别名 (typedef) | 复杂性考虑 | 直接使用类型 |

## 📝 使用建议

### 推荐的编程模式

**1. 优先使用支持完整的特性**:
```dart
// 推荐：使用基础类型和集合
List<int> numbers = [1, 2, 3];
String message = "Hello, World!";

// 避免：复杂的异步模式
// Future<String> complexAsync() async { ... }  // 部分支持
```

**2. 利用类型安全**:
```dart
// 推荐：明确的类型声明
int calculateSum(List<int> numbers) {
  return numbers.fold(0, (sum, n) => sum + n);
}

// 避免：动态类型
// dynamic calculate(dynamic input) { ... }  // 不推荐
```

**3. 使用空安全特性**:
```dart
// 推荐：空安全操作
String? getName() => null;
String displayName = getName() ?? "Anonymous";

// 推荐：空值检查
if (value != null) {
  print(value.toString());
}
```

### 性能优化建议

**1. 字符串操作优化**:
```dart
// 推荐：使用字符串插值
String message = "Hello, $name!";

// 避免：频繁的字符串连接
// String result = "";
// for (var item in items) {
//   result += item.toString();  // 性能较差
// }
```

**2. 集合操作优化**:
```dart
// 推荐：使用高阶函数
var result = numbers
    .where((n) => n > 0)
    .map((n) => n * 2)
    .toList();

// 推荐：预分配容量
List<int> largeList = List.filled(1000, 0);
```
