## 📋 测试概述

### 测试目标

验证 Dart 到 C++ 表达式转换逻辑的正确性、完整性和性能，确保：
1. **转换准确性**：Dart 代码能够正确转换为语义等价的 C++ 代码
2. **编译成功率**：生成的 C++ 代码能够成功编译
3. **运行正确性**：编译后的程序能够正确执行并产生预期结果
4. **性能指标**：转换、编译和运行的整体成功率达到目标值

## 🧪 测试策略

### 1. 测试分层

#### 1.1 单元测试层
**目标**：测试单个转换函数的正确性

**测试范围**：
- 类型推断函数 (`_inferExpressionType`)
- 类型转换函数 (`convertType`)
- 表达式转换函数 (`convertExpression`)
- 各具体表达式转换方法

**测试方法**：
- 使用 Dart test 框架
- 测试文件位于 `test/` 目录
- 每个转换函数至少 10 个测试用例

**示例测试用例**：
```dart
test('类型推断 - 整数字面量', () {
  final expr = IntLiteral(42);
  final type = converter._inferExpressionType(expr);
  expect(type, equals('int'));
});

test('类型转换 - List<int>', () {
  final type = InterfaceType(/* List<int> */);
  final cppType = CppTypeConverter.convertType(type);
  expect(cppType, equals('ObjectPtr<List<Int>>'));
});
```

#### 1.2 集成测试层
**目标**：测试完整的 Dart 文件转换流程

**测试范围**：

- 类型映射的一致性

**测试方法**：
- 使用 `sample/dart/` 目录下的测试文件
- 每个测试文件覆盖特定的 Dart 特性
- 验证生成的 C++ 代码结构

#### 1.3 端到端测试层

## 📈 测试指标定义

### 1. 转换成功率

**定义**：成功转换的 Dart 文件数 / 总 Dart 文件数

**计算公式**：
```
转换成功率 = (转换成功数 / 总文件数) × 100%
```

**成功标准**：
- 生成的 C++ 文件存在且非空
- 没有转换器崩溃或异常
- 生成的代码语法结构完整

**当前值**：100% (19/19)

---

### 2. 编译成功率

**定义**：成功编译的 C++ 文件数 / 总 Dart 文件数

**计算公式**：
```
编译成功率 = (编译成功数 / 总文件数) × 100%
```

**成功标准**：
- C++ 代码能够通过 clang++ 编译
- 没有语法错误
- 没有类型错误
- 生成可执行文件

**当前值**：42% (8/19)

**失败原因分类**：
1. 语法错误：生成的 C++ 代码语法不正确
2. 类型错误：类型映射或转换错误
3. 链接错误：缺少必要的运行时库
4. 头文件错误：include 路径或依赖问题

---

### 3. 运行成功率

**定义**：成功运行的程序数 / 总 Dart 文件数

**计算公式**：
```
运行成功率 = (运行成功数 / 总文件数) × 100%
```

**成功标准**：
- 程序能够正常启动
- 没有运行时崩溃（段错误、异常等）
- 程序正常退出（退出码 0）
- 输出结果符合预期

**当前值**：32% (6/19)

**失败原因分类**：
1. 段错误（Segmentation Fault）：内存访问错误
2. 运行时异常：未捕获的异常
3. 逻辑错误：输出结果不符合预期
4. 超时：程序执行时间超过限制

---

### 4. 端到端成功率

**定义**：完整通过所有阶段的文件数 / 总 Dart 文件数

**计算公式**：
```
端到端成功率 = (完整通过数 / 总文件数) × 100%
```

**成功标准**：
- 转换成功 ✓
- 编译成功 ✓
- 运行成功 ✓
- 输出正确 ✓

**当前值**：32% (6/19)

## 🔍 测试分析方法

### 1. 失败原因分析

#### 1.1 编译失败分析

**分析步骤**：
1. 查看编译错误日志：`sample/test_results.log`
2. 定位错误类型：语法错误、类型错误、链接错误
3. 检查生成的 C++ 代码：`sample/cpp_generated/*.cpp`
4. 对比 Dart 源码：`sample/dart/*.dart`
5. 识别转换逻辑问题

**常见问题模式**：
- 泛型类型转换错误
- ObjectPtr 包装缺失或多余
- 方法调用语法错误
- 类型不匹配

#### 1.2 运行失败分析

**分析步骤**：
1. 检查退出码：识别错误类型
2. 使用调试器：`lldb` 或 `gdb`
3. 检查内存访问：valgrind（如果可用）
4. 添加调试输出：在关键位置添加 print
5. 对比预期输出

**常见问题模式**：
- 空指针解引用
- 数组越界
- 内存泄漏
- 引用计数错误

---

### 2. 性能分析

#### 2.1 转换性能

**指标**：
- 单文件转换时间
- 平均转换速度（行/秒）
- 内存使用峰值

**测量方法**：
```bash
time dart run bin/dart2cpp.dart -o output.cpp input.dart
```

#### 2.2 编译性能

**指标**：
- 单文件编译时间
- 编译器资源使用

**测量方法**：
```bash
time clang++ -std=c++17 -o output output.cpp
```

#### 2.3 运行性能

**指标**：
- 程序启动时间
- 执行时间
- 内存使用

**测量方法**：
```bash
time ./output
```
