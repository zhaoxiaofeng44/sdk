### ✅ 3. 继承和多态（新增）

```cpp
class Animal : public Object {
    virtual String makeSound() const;  // 虚函数
};

class Dog : public Animal {
    String makeSound() const override {  // 重写
        return String("Woof!");
    }
};

// 多态使用
Animal* pet = new Dog(...);
pet->makeSound();  // 调用 Dog 的实现
```

### ✅ 4. 抽象类和接口（新增）

```cpp
class Shape : public Object {
    virtual Double area() const = 0;  // 纯虚函数
    virtual Double perimeter() const = 0;
};

class Circle : public Shape {
    Double area() const override {
        return Double(3.14 * r * r);
    }
};
```

### ✅ 5. 异常处理（新增）

```cpp
try {
    throw ArgumentException(String("Invalid"));

}
```

### ✅ 6. 函数对象和 Lambda（新增）

```cpp
Function<Int, Int, Int> add([](Int a, Int b) {
    return a + b;

Int result = add(Int(10), Int(20));  // 30
```

## 三、完整示例

### 示例1：宠物店管理系统（展示多态）

```cpp
// 创建多态列表
List<ObjectPtr<Animal>> pets;
pets.add(ObjectPtr<Animal>(new Dog(String("Max"), 5, String("Husky"))));
pets.add(ObjectPtr<Animal>(new Cat(String("Luna"), 3, true)));

// 多态调用
for (int i = 0; i < pets.get_length(); i++) {
    ObjectPtr<Animal> pet = pets.get(i);
    std::cout << pet->get_name().toString() << " says: "
              << pet->makeSound().toString() << std::endl;
}
// 输出:
// Max says: Woof! Woof!
// Luna says: Meow! Meow!
```

### 示例2：学生成绩系统（展示泛型）

```cpp
// 嵌套泛型：Map<学生名, List<成绩>>
Map<String, List<Int>> studentScores;

List<Int> aliceScores;
aliceScores.add(Int(95));
aliceScores.add(Int(87));
aliceScores.add(Int(92));
studentScores.set(String("Alice"), aliceScores);

// 计算平均分
List<Int> scores = studentScores.get(String("Alice"));
Int sum(0);
for (int i = 0; i < scores.get_length(); i++) {
    sum = sum + scores.get(i);
}
Double avg(sum.toDouble() / scores.get_length());
std::cout << "Average: " << avg.toString();  // 91.33
```

### 示例3：图形面积计算（展示接口）

```cpp
// 使用抽象类
Shape* shapes[3];
shapes[0] = new Circle(String("red"), 5.0);
shapes[1] = new Rectangle(String("blue"), 4.0, 6.0);
shapes[2] = new Circle(String("green"), 3.0);

// 多态调用纯虚函数
for (int i = 0; i < 3; i++) {
    std::cout << shapes[i]->getShapeType().toString()
              << " area: " << shapes[i]->area().toString() << std::endl;
}
```

## 七、关键设计决策

### 1. 类型统一
- 所有类型都继承自 `Any` 或 `Object`
- 使用 `type_id` 进行运行时类型识别
- 统一的 `toString()` 方法

### 2. 内存管理
- String 使用全局字符串池，节省内存
- ObjectPtr<T> 实现智能指针，自动管理生命周期
- 泛型容器使用 STL，自动扩容和清理

### 3. 泛型实现
- 使用 C++ 模板实现泛型
- 支持任意类型嵌套
- 类型安全

### 4. 多态机制
- 虚函数表实现动态绑定
- 基类指针调用派生类方法
- 支持纯虚函数（抽象类）
